# RisuFold 배포 저장소

RisuFold의 공개 설치 파일, 버전별 변경 사항 및 배포 문서를 제공하는 저장소입니다. 개발 원본과 내부 시험 자료는 포함하지 않습니다.

## 설치 및 업데이트

1. [Releases](https://github.com/marv435624q/risufold-releases/releases)에서 설치할 버전의 배포 안내를 확인합니다.
2. 해당 버전의 **Assets**에서 RisuFold 플러그인 `.js` 파일을 내려받습니다. GitHub가 자동으로 제공하는 `Source code` 압축 파일은 설치 파일이 아닙니다.
3. 사용 중인 호스트의 플러그인 관리 화면에서 파일을 가져옵니다. 지원 환경과 업데이트 시 주의사항은 각 버전의 안내를 따릅니다.

현재 이 저장소에는 설치 파일이 게시되어 있지 않습니다. 기존 설치의 자동 업데이트 주소는 이 저장소 개설만으로 바뀌지 않습니다.
